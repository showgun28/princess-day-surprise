# Princess Day Surprise Website

A mobile-friendly, four-scene interactive Princess Day website made with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — colours, layout and animations
- `script.js` — stars, navigation, envelope, flowers and gift interactions

## Preview on your computer
1. Extract the ZIP file.
2. Open the `princess_day_website` folder.
3. Double-click `index.html` to open it in your browser.
4. Internet is only needed for the optional Google Fonts; the page itself works offline.

## Publish free with GitHub Pages
1. Sign in at https://github.com/ or create a free account.
2. Click **New repository**.
3. Name it `princess-day-surprise`.
4. Set it to **Public**, then create the repository.
5. Click **Add file → Upload files**.
6. Upload `index.html`, `style.css`, and `script.js` (upload the files themselves, not the ZIP).
7. Click **Commit changes**.
8. Open **Settings → Pages**.
9. Under **Build and deployment**, choose **Deploy from a branch**.
10. Select branch **main** and folder **/(root)**, then click **Save**.
11. Wait a few minutes. Your site will be at:
    `https://YOUR-USERNAME.github.io/princess-day-surprise/`
    Replace `YOUR-USERNAME` with your GitHub username.

## Make a QR code
1. Copy your published GitHub Pages URL.
2. Visit https://www.qrcode-monkey.com/
3. Paste the URL and create/download the QR code.
4. Test it by scanning with your phone before sharing.

## Personalise the message
Open `index.html` in a text editor and search for `Princess` or the letter paragraphs. Change the text, save, and upload the updated files to the same GitHub repository.
